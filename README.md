# Cross-Paradigm Benchmark of Foundation Models for Chest Radiograph Classification

Code, probe outputs and result files for the article *Cross-Paradigm Benchmark of Foundation
Models for Chest Radiograph Classification* (N. Hürsoy, F. Gül; manuscript under review).

Nine frozen image encoders (six main encoders and three architecture-matched controls) are
compared as starting points for chest radiograph classification on the complete NIH
ChestX-ray14 release, with linear probes, patient-level bootstrap inference, calibration
controls, clinical operating points, forward-pass latency and an external validation on the
Indiana University chest X-ray collection (NLM Open-i).

Every table, figure and number in the article is generated by `src/make_tables.py` and
`src/make_figures.py` from the JSON files in `results/`.

## Quick check (no images, no GPU needed)

```bash
pip install -r requirements.txt
cd src
python make_tables.py      # -> outputs/tables/*.tex and outputs/numbers.tex (679 number macros)
python make_figures.py     # -> outputs/figures/fig_{macro,heatmap,robustness,reliability,pareto,external}.pdf
python fig1_overview.py    # -> outputs/figures/fig1_overview.pdf
python stats.py            # recomputes results/stats.json from the probe outputs in preds/ (GPU recommended)
```

`outputs/` in this repository already contains the files produced by these commands.

## Contents

| Path | Content |
|---|---|
| `src/common.py` | label table and split, embedding loader, GPU L2 logistic regression, metrics |
| `src/extract_full.py` | frozen-embedding extraction for the nine encoder configurations |
| `src/main.py` | linear probes (class-balanced and unweighted; C selected on validation AUROC) |
| `src/stats.py` | patient-level cluster bootstrap, pairwise tests with Holm correction and a pre-specified equivalence margin of 0.01 macro AUROC, calibration, operating points |
| `src/replicates.py` | small-sample re-draws, learning curves, alternative partitions, Kendall's W |
| `src/external.py` | Open-i external validation (`extract`, `views`, `eval`) |
| `src/latency.py` | forward-pass latency (GPU batch 1/32, fp32/fp16; CPU batch 1) |
| `src/original_subset.py` | small-sample sensitivity analysis on a fixed 3,000-image subset (Table A1) |
| `src/make_tables.py`, `src/make_figures.py`, `src/fig1_overview.py`, `src/fig_examples.py` | tables, number macros and figures |
| `results/*.json` | all result files used by the article |
| `preds/*.npz` | probe outputs: validation/test logits, selected weights and C for every encoder and training scheme |
| `data/nih_split.csv` | image name, patient ID, split (train/val/test) and the 14 labels for all 112,120 images |
| `data/openi_views.csv` | frontal/lateral assignment of the Open-i images |
| `data/original_subset/` | the fixed 3,000-image subset and the values reported for Pipeline A |

## Full reproduction

1. **Data.** NIH ChestX-ray14 (NIH Clinical Center; mirrored on Hugging Face as
   `alkzar90/NIH-Chest-X-ray-dataset`): set `NIH_ZIPS` to the folder with `images_001.zip` …
   `images_012.zip` and `NIH_DATA` to the folder with `Data_Entry_2017_v2020.csv`,
   `train_val_list.txt` and `test_list.txt`. The official test split is used unchanged; the
   train/validation partition is a patient-level 90/10 split of the official train/validation
   list with seed 20260531 (`data/nih_split.csv`). Open-i: the PNG images and XML reports of
   the Indiana University collection from NLM Open-i, placed under `$RUN_OUT/openi/`.
2. **Embeddings.** `RUN_OUT=/path/to/workdir python extract_full.py` (≈ 9 encoder
   configurations × 112,120 images; about 9 h on one RTX 3070 Laptop GPU), then
   `python external.py extract && python external.py views`.
3. **Probes and statistics.** `python main.py && python stats.py && python replicates.py &&
   python external.py eval && python latency.py`.
4. **Tables and figures.** as in the quick check.

Encoders (public checkpoints): `microsoft/rad-dino` (at 518² and 224²), `facebook/dinov2-base`
(518² and 224²), `facebook/dinov2-small`, `microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224`
(open_clip), `openai/clip-vit-base-patch16` (projected image embedding), timm
`resnet50.a1_in1k` and `vit_base_patch16_224.augreg2_in21k_ft_in1k`. Each receives its own
published normalisation; images are resized from the original 1024² PNGs directly to the
encoder's input size.

Note: the public RAD-DINO checkpoint was pretrained (without labels) on images that include
all of NIH ChestX-ray14, the official test split among them, but on no Open-i image; this is
discussed in the article.

## Environment

Python 3.13, PyTorch 2.6 (CUDA 12.4), transformers 5.9, timm 1.0, open_clip 3.3,
scikit-learn 1.8, NumPy 2.5, pandas 2.3, SciPy 1.16, Matplotlib 3.10. Hardware: NVIDIA RTX
3070 Laptop GPU (8 GB), Intel Core i7-11370H.
